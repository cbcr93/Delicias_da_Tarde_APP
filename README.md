# 📱 Base React Native com Expo + TypeScript

Este projeto é uma base para desenvolvimento de apps em **React Native** usando **Expo** e **TypeScript**.

---

## 🚀 Requisitos

Antes de começar, certifique-se de ter os seguintes itens instalados:

- [Node.js](https://nodejs.org/) (recomendado: LTS)
- [Git](https://git-scm.com/)
- [Expo CLI via `npx`] (não é mais necessário instalar globalmente)
- Um editor como [VSCode](https://code.visualstudio.com/)
- (Opcional) [Expo Go app](https://expo.dev/client) no celular

---

## 📦 Instalação

1. **Clone o repositório**

```bash
    git clone https://github.com/seu-usuario/seu-projeto.git
    cd seu-projeto
    npm run format
```

2. **Instale as dependências**

```bash
    npm install
    npm run format
```

3. **Inicie o servidor de desenvolvimento**

```bash
    npx expo start
```

4. **Escolha como abrir o app:**

- Celular com Expo Go (leia o QR code)
- Emulador Android (via Android Studio)
- Simulador iOS (apenas em Mac com Xcode)

---

## Executáveis

1. **Lint**

```bash
   npx expo lint
```

2. **Formatação**

```bash
   npm run format
```
